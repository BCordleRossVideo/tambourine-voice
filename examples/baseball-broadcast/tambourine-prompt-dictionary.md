### Phonetic Corrections
These are terms STT engines consistently get wrong:
- "ribby" or "ribbies" = RBI / RBIs
- "whip" (in pitching context) = WHIP
- "Kay" or "case" (in strikeout context) = K / Ks
- "oh PS" or "opps" = OPS
- "oh BP" = OBP
- "punch out" = strikeout
- "can of corn" = routine fly ball
- "dinger" = home run
- "going yard" = hitting a home run
- "painting the corner" = precise pitch on the edge of the strike zone
- "frozen rope" = hard line drive
- "seeing eye single" = seeing-eye single
- "twin killing" = double play
- "bases juiced" = bases loaded
- "punch and judy" = light-hitting contact style
- "meatball" = easy-to-hit pitch
- "high cheese" = high fastball
- "chin music" = pitch thrown high and inside
- "tape measure shot" = very long home run
- "walk off" = walk-off (hyphenated as adjective)
- "grand salami" = grand slam
